## Overview

This repository is intended to provide the source code associated with the manuscript entitled **"Investigation of True and Spurious Eigenvalues and Animation of Membrane Eigenmodes"**, submitted to the *Journal of Vibration Engineering & Technologies* (JVET).

The present study employs the dual boundary element method (BEM) combined with singular value decomposition (SVD) to investigate membrane eigenvalue problems governed by the two-dimensional Helmholtz equation.

## Research Scope

- Eigenvalue search
- Identification of true and spurious eigenvalues
- Eigenvalue multiplicity determination
- Vibration-mode reconstruction
- Taking-free-body analysis
- Modal animation

## Numerical Examples

- Circular membrane
- Annular membrane
- Regular triangular membrane: (3, 1)-gon
- Star-shaped membrane: (5, 2)-gon
- Star-shaped membrane: (7, 3)-gon
- L-shaped membrane
